== Klassenbeschreibung
=== Topic `+Stammdaten+`
Das Topic `+Stammdaten+` umfasst alle statischen Werte. Darunter fallen z.B. die Aufzählwerte von Listen (INTERLIS-Datentyp «Aufzählung»). Jede Liste wird in einer eigenen Klasse modelliert.

Die Stammdaten werden durch die zuständige Stelle vorgegeben. Bei Bundesthemen ist dies das für die Modellierung zuständige Bundesamt. Bei kantonalen Themen das zuständige kantonale Amt. Die Stammdaten von Bundesthemen können auf der Stufe Kanton erweitert werden. Die kantonalen Erweiterungen werden bei der Überführung ins Bundesmodell den entsprechenden Bundestypen zugeordnet. Bei Bedarf werden die Stammdaten durch die Abteilung Geoinformation nachgeführt und im https://github.com/ch-sz-geo/<Themennummer>/tree/main/data[data-Verzeichnis] des jeweiligen Themas veröffentlicht.

==== Klasse `+Landnutzungsklasse+`
Die Klasse `+Landnutzungsklasse+` führt die Werte des Katalogs "Landnutzungsklasse". Sie ist eine Spezialisierung der Klasse `+Katalogeintrag+` und führt keine weiteren Attribute.

Das ganze Kantonsgebiet ist in Flächen aufgeteilt, welche einer der folgenden Klassen entspricht:

* Siedlung
* Verkehr
* Grünfläche
* Restfläche

Diese Flächen bilden die Basis für die Bewertungskarten sowie die Planungshinweiskarte.

==== Klasse `+Wirkungstyp+`
Die Klasse `+Wirkungstyp+` führt die Werte des Katalogs "Wirkungstyp". Sie ist eine Spezialisierung der Klasse `+Katalogeintrag+` und führt keine weiteren Attribute.

Im Zuge der Klimaanalyse wird jede Fläche der Landnutzungstypen "Siedlung", "Verkehr" und "Grünfläche" bewertet. Die Werte dieser Bewertung sind für alle drei Landnutzungen gleich und im Katalog "Wirkungstyp" zusammengefasst.

==== Klasse `+Aufenthaltsqualitaet+`
Die Klasse `+Aufenthaltsqualitaet+` führt die Werte des Katalogs "Aufenthaltsqualitaet". Sie ist eine Spezialisierung der Klasse `+Katalogeintrag+` und führt keine weiteren Attribute. Die Datenquelle ist "bw_artag" der Original-Datenquelle.

Bei hohen Tagestemperaturen kann der Aufenthalt im Wald oder auf Wiesen als angenehm empfunden werden. Die Höhe dieses Effektes wird über den Wert "Aufenthaltsqualitaet" ausgewiesen und für jede Fläche des Landnutzungstyps "Grünfläche" aus den Klimaanalysekarten berechnet.

==== Klasse `+Schutzbedarf+`
Die Klasse `+Schutzbedarf+` führt die Werte des Katalogs "Schutzbedarf". Sie ist eine Spezialisierung der Klasse `+Katalogeintrag+` und führt keine weiteren Attribute. Die Datenquelle ist "phk_ar" der Original-Datenquelle.

Grünflächen weisen eine ausgleichende Wirkung auf hohe Temperaturen auf. Je höher dieser Effekt ist, desto eher sollte der Bestand der Grünfläche bei zukünftigen Vorhaben gesichert werden. Dieser Schutzbedarf ist in der Planungshinweiskarte für jede Grünfläche ausgewiesen.
